# Autonomous Vehicle Simulator — Neural Networks (GA & DQN)

A neural network learns to drive a car around a winding track using only distance
sensors, trained by **two techniques**: neuroevolution (a shallow MLP + a genetic
algorithm) and **DQN**. Packaged for the browser with **pygbag** (WebAssembly).
